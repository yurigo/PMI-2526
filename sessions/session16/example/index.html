⚡ Comandos básicos

Comando Descripción
git init Inicializa un repositorio Git en la carpeta actual
git status Muestra el estado del repositorio (archivos modificados, en staging, etc.)
git add . Añade todos los cambios al área de preparación (staging)
git commit -m "mensaje" Guarda los cambios del staging con un mensaje descriptivo
git push Sube los commits locales al repositorio remoto (GitHub)
git pull Descarga y fusiona los cambios remotos en la rama local actual
git log --oneline Muestra el historial de commits de forma resumida

🌳 Árbol local vs. árbol remoto

Local (tu máquina) Remote (GitHub) ────────────────── ─────────────── commit C ◄── git pull ── commit C commit B ──── git push ──► commit B commit A commit A

🌿 Ramas (branches)

Comando Descripción
git branch Lista las ramas locales (la rama activa aparece con *)
git branch develop Crea la rama develop
git checkout develop Cambia a la rama develop
git checkout -b develop Crea y cambia a develop en un solo paso
git checkout master Vuelve a la rama principal
git merge develop Fusiona develop en la rama activa (master)
develop: A──B──C \ master: A───────M ← merge commit

🔄 Flujo de trabajo completo

1

Cambia a la rama de desarrollo

git checkout develop
2

Edita los archivos en VSCode

3

Añade los cambios al staging

git add .
4

Guarda un commit descriptivo

git commit -m "feat: nueva sección de contacto"
5

Sube a GitHub (rama develop)

git push
6

Abre un Pull Request en GitHub: develop → master

7

Revisa y aprueba el Pull Request

8

Fusiona en master y despliega

git checkout master  →  git merge develop  →  git push

🚀 Vercel — CI/CD con GitHub

Evento en GitHub Acción de Vercel
git push a master Producción Despliega en la URL pública
git push a develop Preview Genera una URL de previsualización
Pull Request abierto Preview Crea automáticamente una URL de preview del PR

🖥️ Git desde VSCode (interfaz)

Acción en terminal Equivalente en VSCode
git add . Clic en + junto al archivo o en Stage All Changes
git commit -m "msg" Escribe el mensaje en el campo de texto y pulsa ✓ Commit
git push Botón Sync Changes ↑
git pull Botón Sync Changes ↓

Abre el panel con Ctrl + Shift + G o haciendo clic en el icono de bifurcación de la barra lateral.
