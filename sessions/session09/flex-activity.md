# 🧩 ACTIVIDAD (2h) -- Maquetación con Flexbox

## Landing Page -- Evento Tecnológico

## 🎯 Objetivo

Maquetar una landing page moderna y responsive utilizando principalmente
**Flexbox** para estructurar y alinear todos los bloques.

---

## ⏱️ Duración

2 horas

---

## 🚫 Restricciones

No se permite usar:

- CSS Grid
- Frameworks (Bootstrap, Tailwind, etc.)
- float
- position para estructurar el layout principal

Solo se permite:

- HTML5 semántico
- CSS externo
- Flexbox

---

## 📄 Estructura Obligatoria

La página debe contener las siguientes secciones:

### 1️⃣ Header

- Logo a la izquierda
- Menú de navegación a la derecha (4 enlaces)

---

### 2️⃣ Hero Section

Debe contener:

- Título
- Párrafo descriptivo
- Botón "Regístrate"
- Imagen

---

### 3️⃣ Sección de Ponentes (Cards)

4 tarjetas con:

- Imagen
- Nombre
- Descripción breve
- Botón "Ver perfil"

Debe resolverse con:
-flex-wrap
-flex-basis
-flex-grow

No se permite usar width fija en píxeles para las columnas.

---

### 4️⃣ Agenda / Horario

Estructura en dos columnas:

- Columna izquierda → Horarios
- Columna derecha → Descripción del evento

---

### 5️⃣ Footer

Tres bloques:

- Información
- Enlaces
- Redes sociales

Distribuidos horizontalmente y correctamente alineados.

---

## 📱 Requisitos Técnicos Evaluables

Debe utilizarse correctamente:

- display: flex
- flex-direction
- justify-content
- align-items
- flex-wrap
- flex-grow
- flex-basis

---

## 🎨 Requisitos de Diseño

- CSS externo correctamente enlazado
- Google Fonts
- Espaciado consistente
- Uso correcto del box-model

---

## 🔥 Bonus (Opcional)

Explora el concepto de pseudoclase: `:hover` y aplicalo en los botones.
